## Overview

Throughout the **08-week** program, I followed a learning path that combined theoretical knowledge with hands-on practice on AWS cloud services. In addition to studying core AWS services such as Amazon EC2, Amazon S3, Amazon DynamoDB, and Amazon SageMaker, I participated in the development of a real-world full-stack project, using Docker for application containerization and deploying the system on AWS.

The program provided valuable opportunities to develop teamwork skills, manage source code with Git and GitHub, deploy applications using Docker Compose, integrate applications with AWS services, and gain an understanding of the Machine Learning development workflow on the cloud. The knowledge and practical experience gained throughout the project serve as a strong foundation for further research and development of cloud-based applications in the future.

The detailed worklog for each week is presented below.

### Week 1: [Getting Started with AWS and Setting Up the Environment](1.1-week1/)

Get familiar with the FCAJ program, create an AWS Account and IAM User, install the AWS CLI, and learn the fundamental concepts of AWS.

### Week 2: [Working with Amazon S3 and Amazon DynamoDB](1.2-week2/)

Learn AWS data storage services, practice creating an S3 Bucket and a DynamoDB Table, and connect the application using the AWS SDK.

### Week 3: [Exploring Amazon EC2 and the Deployment Environment](1.3-week3/)

Practice creating an EC2 Instance, configuring Security Groups, connecting via SSH, and preparing the server environment for application deployment.

### Week 4: [Docker and Docker Compose](1.4-week4/)

Learn Docker, build Docker Images, write Dockerfiles, and use Docker Compose to manage the application's services.

### Week 5: [Project Initialization and Development](1.5-week5/)

Design the system architecture, develop the frontend and backend, and connect the application to Amazon S3 and Amazon DynamoDB.

### Week 6: [Learning Amazon SageMaker and Building the Recommendation System](1.6-week6/)

Study the Machine Learning workflow on AWS, prepare the dataset, design the recommendation pipeline, and integrate the backend with Amazon SageMaker.

### Week 7: [Deploying the Application to AWS](1.7-week7/)

Deploy the project to Amazon EC2 using Docker Compose, configure GitHub Actions, and test the deployment workflow.

### Week 8: [Project Completion and Program Summary](1.8-week8/)

Test the complete system, finalize the technical documentation, prepare the project presentation, and summarize the experience gained throughout the First Cloud AI Journey program.
