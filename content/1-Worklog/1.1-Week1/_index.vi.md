## Kết quả đạt được tuần 1

Sau tuần đầu tiên, đã hoàn thành các nội dung cơ bản để chuẩn bị cho quá trình học tập và thực hành trên AWS.

Một số kết quả đạt được gồm:

- Hiểu được khái niệm Cloud Computing và vai trò của AWS trong việc cung cấp dịch vụ điện toán đám mây.
- Nắm được các nhóm dịch vụ phổ biến của AWS như:
  - Compute
  - Storage
  - Database
  - Networking
  - Security & Identity Management

- Tạo thành công tài khoản AWS và làm quen với AWS Management Console.
- Hiểu được cách tổ chức các dịch vụ trên giao diện AWS Console và cách tìm kiếm service.

- Cài đặt thành công AWS CLI trên máy tính.

- Cấu hình AWS CLI với:
  - AWS Access Key ID
  - AWS Secret Access Key
  - Default Region
  - Output Format

- Thực hiện thành công một số lệnh AWS CLI cơ bản như:
  - `aws configure`
  - `aws sts get-caller-identity`
  - `aws ec2 describe-regions`
  - `aws s3 ls`

- Tìm hiểu các thành phần cơ bản của Amazon EC2:
  - EC2 Instance
  - Amazon Machine Image (AMI)
  - Security Group
  - Key Pair
  - Elastic IP

- Chuẩn bị đầy đủ môi trường và kiến thức nền để thực hiện các bài thực hành AWS trong những tuần tiếp theo.
