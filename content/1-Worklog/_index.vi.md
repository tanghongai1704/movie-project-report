## Tổng quan

Trong suốt **08 tuần** tham gia chương trình, em được tiếp cận với lộ trình học tập kết hợp giữa lý thuyết và thực hành về các dịch vụ điện toán đám mây của AWS. Song song với việc tìm hiểu các dịch vụ cốt lõi như Amazon EC2, Amazon S3, Amazon DynamoDB và Amazon SageMaker, em còn tham gia phát triển một dự án thực tế theo mô hình full-stack, sử dụng Docker để đóng gói ứng dụng và triển khai trên môi trường AWS.

Thông qua chương trình, em có cơ hội rèn luyện kỹ năng làm việc nhóm, quản lý source code với Git/GitHub, triển khai ứng dụng bằng Docker Compose, kết nối ứng dụng với các dịch vụ AWS và tìm hiểu quy trình xây dựng hệ thống Machine Learning trên nền tảng Cloud. Những kiến thức và kinh nghiệm tích lũy được trong suốt quá trình thực hiện dự án là nền tảng quan trọng để tiếp tục nghiên cứu và phát triển các ứng dụng Cloud trong tương lai.

Nội dung chi tiết của từng tuần được trình bày dưới đây.

### Tuần 1: [Làm quen với AWS và thiết lập môi trường](1.1-week1/)

Làm quen với chương trình FCAJ, tạo AWS Account, IAM User, cài đặt AWS CLI và tìm hiểu các kiến thức nền tảng về AWS.

### Tuần 2: [Làm việc với Amazon S3 và Amazon DynamoDB](1.2-week2/)

Tìm hiểu các dịch vụ lưu trữ dữ liệu trên AWS, thực hành tạo S3 Bucket, DynamoDB Table và kết nối ứng dụng thông qua AWS SDK.

### Tuần 3: [Tìm hiểu Amazon EC2 và môi trường triển khai](1.3-week3/)

Thực hành tạo EC2 Instance, cấu hình Security Group, kết nối SSH và chuẩn bị môi trường máy chủ cho việc triển khai ứng dụng.

### Tuần 4: [Docker và Docker Compose](1.4-week4/)

Làm quen với Docker, xây dựng Docker Image, viết Dockerfile và sử dụng Docker Compose để quản lý các service của ứng dụng.

### Tuần 5: [Khởi tạo và phát triển project](1.5-week5/)

Thiết kế kiến trúc hệ thống, xây dựng frontend và backend, kết nối ứng dụng với Amazon S3 và Amazon DynamoDB.

### Tuần 6: [Tìm hiểu Amazon SageMaker và Recommendation System](1.6-week6/)

Nghiên cứu quy trình Machine Learning trên AWS, chuẩn bị dữ liệu, xây dựng luồng Recommendation và tích hợp backend với Amazon SageMaker.

### Tuần 7: [Triển khai ứng dụng lên AWS](1.7-week7/)

Triển khai project lên Amazon EC2 bằng Docker Compose, cấu hình GitHub Actions và kiểm thử quá trình triển khai.

### Tuần 8: [Hoàn thiện project và tổng kết](1.8-week8/)

Kiểm thử toàn bộ hệ thống, hoàn thiện tài liệu kỹ thuật, chuẩn bị báo cáo và tổng kết quá trình tham gia chương trình First Cloud AI Journey.
