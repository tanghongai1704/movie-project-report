Phần này tổng hợp quá trình học tập và thực hiện chương trình **First Cloud AI Journey (FCAJ)** trong **12 tuần**. ## Tổng quan

Trong suốt 12 tuần tham gia chương trình, quá trình học tập được thực hiện theo lộ trình từ kiến thức nền tảng đến thực hành và phát triển dự án. Các nội dung bao gồm tìm hiểu các dịch vụ AWS phổ biến, thực hành triển khai tài nguyên trên Cloud, xây dựng ứng dụng sử dụng Docker và các dịch vụ AWS, đồng thời tích hợp Machine Learning vào project trước khi hoàn thiện báo cáo và demo sản phẩm.

Nội dung chi tiết của từng tuần được trình bày dưới đây.

### Tuần 1: [Làm quen với AWS và môi trường làm việc](1.1-week1/)

Tìm hiểu tổng quan về AWS, làm quen với AWS Management Console, AWS CLI và chuẩn bị môi trường học tập.

### Tuần 2: [Tìm hiểu IAM, Amazon S3 và Amazon EC2](1.2-week2/)

Tìm hiểu cơ chế quản lý người dùng, phân quyền trên AWS, thực hành với Amazon S3 và Amazon EC2.

### Tuần 3: [Tìm hiểu Amazon VPC và Networking](1.3-week3/)

Làm quen với kiến trúc mạng trên AWS, cấu hình VPC, Subnet, Route Table và Security Group.

### Tuần 4: [Tìm hiểu Docker và Docker Compose](1.4-week4/)

Tìm hiểu công nghệ Container, thực hành xây dựng Docker Image và triển khai ứng dụng bằng Docker Compose.

### Tuần 5: [Làm việc với Amazon S3, DynamoDB và AWS SDK](1.5-week5/)

Thực hành lưu trữ dữ liệu trên Amazon S3, Amazon DynamoDB và kết nối ứng dụng thông qua AWS SDK.

### Tuần 6: [Tìm hiểu AWS Lambda và Amazon API Gateway](1.6-week6/)

Làm quen với kiến trúc Serverless, xây dựng Lambda Function và triển khai REST API bằng Amazon API Gateway.

### Tuần 7: [Tìm hiểu Amazon SageMaker](1.7-week7/)

Nghiên cứu quy trình xây dựng và triển khai mô hình Machine Learning trên AWS bằng Amazon SageMaker.

### Tuần 8: [Khởi động và xây dựng kiến trúc project](1.8-week8/)

Thiết kế kiến trúc hệ thống, phân chia công việc và bắt đầu phát triển frontend, backend cùng các dịch vụ AWS.

### Tuần 9: [Tích hợp Machine Learning và hoàn thiện chức năng](1.9-week9/)

Hoàn thiện các chức năng chính của hệ thống, tích hợp Machine Learning và kiểm thử luồng hoạt động của ứng dụng.

### Tuần 10: [Triển khai ứng dụng lên AWS](1.10-week10/)

Triển khai project lên Amazon EC2 bằng Docker, cấu hình môi trường và kiểm thử hệ thống sau khi deploy.

### Tuần 11: [Kiểm thử và hoàn thiện project](1.11-week11/)

Tối ưu giao diện, kiểm thử toàn bộ hệ thống, hoàn thiện tài liệu kỹ thuật và chuẩn bị nội dung báo cáo.

### Tuần 12: [Tổng kết và báo cáo](1.12-week12/)

Hoàn thiện báo cáo, trình bày và demo sản phẩm, đồng thời tổng kết những kiến thức và kinh nghiệm đạt được sau chương trình.
