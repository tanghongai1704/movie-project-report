## Week 5 Objectives

- Learn about Amazon S3 and Amazon DynamoDB.

## Week 5 Outcomes

By the end of the fifth week, a better understanding was gained of common AWS data storage services, and applications could be connected with these services.

The key achievements include:

- Understood the role of Amazon S3 in storing data and files.
- Understood the structure of Amazon DynamoDB and how data is organized using the NoSQL model.
- Successfully created:
  - Amazon S3 Bucket.
  - Amazon DynamoDB Table.
  - IAM Policy for granting access permissions.

- Used AWS SDK (Boto3) to:
  - Connect to Amazon S3.
  - Connect to Amazon DynamoDB.
  - Perform basic data read and write operations.

- Successfully uploaded sample data to Amazon S3 for project development purposes.

- Understood the process of connecting applications with AWS services through Access Keys and IAM Users.

- Prepared the data storage environment required for developing features in the following weeks.
