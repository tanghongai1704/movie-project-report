### [Event 1](4.1-Event1/)
&emsp;**Event Name:** AWS Cloud Technology Sharing Session

&emsp;**Date and Time:** 09:00, June 13, 2026

&emsp;**Location:** 26th Floor, Bitexco Financial Tower, 2 Hai Trieu Street, Sai Gon Ward, Ho Chi Minh City

&emsp;**Role:** Participant

&emsp;**Description:**

&emsp;The event featured a series of presentations on AWS technologies and cloud services. Topics included Docker and containerization, cyber attack detection using Machine Learning on AWS, building multiplayer applications with AWS WebSockets, using Amazon Neptune to build a Knowledge Base for GraphRAG, career development from IT Helpdesk to Cloud/DevOps, and effective teamwork practices.

&emsp;Through these presentations, participants gained valuable insights into applying Cloud, AI, and DevOps technologies in real-world systems while expanding their understanding of modern application development and operations.

&emsp;**Outcomes:**

&emsp;After attending the event, I gained a deeper understanding of AWS technologies such as containerization, Machine Learning for security, cloud-based WebSockets, and Graph Databases. Beyond the technical knowledge, the event also reinforced the importance of teamwork, self-learning, and career development in the Cloud and DevOps fields.

### [Event 2](4.2-Event2/)
&emsp;**Event Name:** GenAI-powered App-DB Modernization Workshop

&emsp;**Date and Time:** 09:00, August 13, 2025

&emsp;**Location:** 26th Floor, Bitexco Financial Tower, 2 Hai Trieu Street, Sai Gon Ward, Ho Chi Minh City

&emsp;**Role:** Participant

&emsp;**Description:**

&emsp;The workshop focused on modernizing applications and databases using contemporary technologies. The main topics included Domain-Driven Design (DDD), Event-Driven Architecture, Microservices Architecture, strategies for selecting AWS Compute Services, and the use of AI-powered development tools such as Amazon Q Developer.

&emsp;The event helped participants gain a better understanding of modern system design, application scalability, reducing dependencies between system components, and applying software engineering practices suitable for real-world environments.

&emsp;**Outcomes:**

&emsp;After attending the workshop, I gained additional knowledge of modern application architecture patterns such as Microservices, Event-Driven Architecture, and Domain-Driven Design. I also learned more about selecting appropriate AWS services, integrating AI into software development workflows, and designing scalable systems.
